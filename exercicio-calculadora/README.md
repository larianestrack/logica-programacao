\# Calculadora



Este projeto apresenta uma calculadora desenvolvida em Shell Script e Python.



\## 1. Como executar o arquivo calculadora.sh



O arquivo calculadora.sh é um script desenvolvido em Shell Script.



Para executar o arquivo no Linux, primeiro é necessário dar permissão de execução:



chmod +x calculadora.sh



Depois, execute o arquivo com o comando:



./calculadora.sh



Também é possível executar utilizando:



bash calculadora.sh



\## 2. Explicação do código em Python



O arquivo calculadora.py contém uma calculadora desenvolvida em Python.



Primeiramente, o programa solicita o nome do usuário e apresenta uma mensagem de boas-vindas.



Em seguida, solicita dois números para realizar os cálculos.



O programa apresenta quatro opções de operação:



\- Adição

\- Subtração

\- Multiplicação

\- Divisão



O usuário escolhe a operação desejada.



Na subtração, o programa verifica se o resultado é negativo e informa o usuário.



Na divisão, o programa verifica se o segundo número é diferente de zero. Caso seja zero, o programa informa que não é possível realizar a divisão.



Depois de realizar o cálculo, o programa pergunta se o usuário deseja realizar outra operação. Caso a resposta não seja "s", a calculadora é encerrada.
